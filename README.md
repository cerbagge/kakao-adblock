# kakao-adblock

**한국어** | [English](README.en.md)

Windows용 카카오톡 PC 광고 차단기이자, 화면 오른쪽 아래에 뜨는 팝업을 허용 목록 방식으로 차단하는 작은 상주 프로그램입니다.

- 카카오톡 실행 파일은 **수정하지 않습니다**. 실행 중인 광고 창만 숨깁니다.
- 주기적으로 검사하지 않고 Windows 창 이벤트(WinEvent 훅)가 올 때만 깨어나므로, 대기 중 CPU 사용량은 0%이고 메모리는 약 1MB입니다.
- 콘솔 창이나 트레이 아이콘이 없고, 실행 파일 하나(약 150KB)로 동작합니다.

## 동작 방식

1. **카카오톡 광고**: 카카오톡 창 중에서 제목에 "광고"가 들어간 크로미움 뷰(예: `MOMENT 광고`)를 가진 창을 숨깁니다. 카카오톡 메인 창은 숨기지 않습니다.
   - 메인 창 하단의 광고 자리도 숨기고, 채팅·친구 목록을 창 아래 끝까지 늘립니다. 창 크기를 바꿔도 카카오톡 프로세스에 한정한 위치·크기 변경 이벤트로 다시 맞춥니다.
2. **오른쪽 아래 팝업**: `allow.txt`에 없는 프로그램이 다음 조건을 모두 만족하는 창을 띄우면 숨깁니다.
   - 제목 표시줄이 없는 최상위 창
   - 800×600 이하 크기
   - 모니터 작업 영역의 오른쪽 아래 구역에 위치 (미끄러져 들어오는 팝업 포함)
3. `C:\Windows` 아래의 시스템 프로그램과 Windows 기본 알림(알림 센터 토스트)은 항상 허용합니다. Windows 기본 알림은 `설정 → 시스템 → 알림`에서 앱별로 관리하시면 됩니다.

## 설치

1. [Releases](../../releases)에서 최신 `kakao-adblock-*.zip`을 내려받아 원하는 폴더에 압축을 풉니다.
2. `kakao-adblock.exe`를 실행합니다. 처음 실행하면 같은 폴더에 `allow.txt`가 만들어집니다.
3. 로그인할 때마다 자동으로 실행하려면 `Win + R` → `shell:startup`을 입력해 열리는 폴더에 `kakao-adblock.exe`의 바로 가기를 넣습니다.

종료하려면 작업 관리자에서 `kakao-adblock.exe`를 끝내거나 다음 명령을 실행합니다.

```
taskkill /IM kakao-adblock.exe
```

## 설정 (`allow.txt`)

오른쪽 아래 팝업을 허용할 프로그램의 실행 파일 이름을 한 줄에 하나씩 적습니다. 대소문자는 구분하지 않으며, 수정한 뒤에는 프로그램을 다시 실행해야 반영됩니다.

```
KakaoTalk.exe
Discord.exe
```

필요한 팝업이 사라졌다면 같은 폴더의 `blocked.log`를 확인하십시오. 어떤 프로그램의 창을 숨겼는지 기록되어 있으므로, 그 이름을 `allow.txt`에 추가하시면 됩니다. 로그가 256KB를 넘으면 다음 실행 때 초기화됩니다.

반대로 광고 팝업이 숨겨지지 않았다면 `blocked.log`에서 `[참고: ...]` 줄을 찾아보십시오. 오른쪽 아래 구역에 떴지만 제목 표시줄이 있거나 크기가 커서 숨기지 않은 창이 위치·크기와 함께 기록됩니다.

## 빌드

```
cargo build --release
```

`examples/popup_test.rs`는 오른쪽 아래 팝업과 대조군 팝업을 띄워 차단 여부를 출력하는 검증용 프로그램입니다.

```
cargo run --release --example popup_test
```

## 주의

- 창 구조를 기준으로 판별하므로, 카카오톡이 업데이트되어 광고 창 구조가 바뀌면 차단되지 않을 수 있습니다.
- 이 프로그램은 카카오와 관련이 없는 비공식 프로그램입니다.
